---

title: "**The KPM Mods**"

---

KotOR Patch Manager patches target KOTOR executables. But some patches require modifications to other game files in order to be used (or fully enjoyed). This mod collection allows you to make those modifications.   *Note: An attendant modification does not obviate the need to use KPM to install the patch itself.*

**Install instructions:**

1.	Point HoloPatcher to the KPM Mods Folder and select the relevant KOTOR directory path.
	+ For native Windows players: the folder that contains your KOTOR.exe.
	+ For native Mac players: the folder inside your game called “Assets” (KOTOR 1) or “GameData” (KOTOR 2).
	+ For native Linux users: the “steamassets” folder inside of your game directory.
2.	Use the top drop-down menu to select one of the patches you plan to use. Click install. 
3.	Repeat step 2, as necessary.
